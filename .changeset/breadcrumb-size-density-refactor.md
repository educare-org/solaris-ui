Add `density` (`compact` | `normal` | `comfortable`) to `solaris-breadcrumb` as `input<T | undefined>` with `effectiveDensity` falling back to `ThemeService.density`; the host exposes `data-density` (effective) alongside `data-size`. The SCSS now has the explicit 3x3 `size` x `density` matrix on the control host: `size` scales font, item/separator icons, pager size, and label max-width (`sm`: 120px, `md`: 200px, `lg`: 280px), while `density` controls the inter-item gap (`compact`: `spacing-2`, `normal`: `spacing-3`, `comfortable`: `spacing-4`) on its own spacing scale (breadcrumb does not derive from `--solaris-control-height-*`). Also adds label truncation (ellipsis + `max-width` per size with `min-width: 0` on flex items) with the full label exposed through the native `title` tooltip on links and text, and fixes the docs CSS-variables table to match the code (link color `text-muted`, gap `spacing-3`, icon/separator defaults) plus new `When to use / not to use` and `Limitations (v1)` sections. The showcase page is rebuilt on the docs-page-layout pattern (preview-code per example, tabs for separators and overflow positions, interactive size+ density selectors with computed code, truncation and pager examples, simple installation, props placeholder, full i18n). Follow-ups: routerLink binding on items, automatic responsive collapsing, SEO/json-ld emission.
