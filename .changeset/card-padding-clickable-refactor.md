Refactor `solaris-card`: remove `size` (`sm | md | lg`) and add `padding` (`none | sm | md | lg`, default `none`, zero-spacing v2 preserved). Padding selects a spacing tier that composes with `density` through the `--solaris-density-*` tokens (compact tighter, comfortable looser), so no control-height ladder is needed — card is a fluid container, not a fixed-height control. Migrate `size="sm"` to `padding="sm"`, `size="md"` to `padding="md"`, `size="lg"` to `padding="lg"`; cards without `size` already render `padding="none"` and need no change. The side-media thumb keeps its scale (`sm` tier to `spacing-10`, `lg` tier to `spacing-16`). Also adds clickable cards: setting `href` renders a native link overlay covering the whole surface (`data-clickable`, hover elevation, `focus-visible` ring via the global focus tokens, `target`/`rel` forwarding with `noopener` default for `_blank`, `disabled` removes the target and exposes `aria-disabled` + `tabindex="-1"`). The overlay is named via `ariaLabel`/`ariaLabelKey`; one card is one destination and interactive children are forbidden (use `solaris-card-actions` with explicit buttons for multi-action cards, `solaris-selection-card` for selectable options). A card with a single section (only a header or only a footer) suppresses the separator border automatically via `data-single-section` — there is nothing to separate from. The showcase page is rebuilt on the docs-page-layout pattern (preview-code per example, tabs for appearance/radius/media, interactive padding-density selectors with computed snippet, clickable demo, composition demo with a loaded/loading toggle showing the skeleton variant, simple installation, props placeholder, full en-US + pt-BR i18n). Follow-ups: media `aspect-ratio`, metric/profile/media presets, component harness.
