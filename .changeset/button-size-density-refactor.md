Add `size` (`sm` | `md` | `lg`, default `md`) to `solaris-button`, combining with `density` into the same 3×3 `size` × `density` matrix as Tabs/Segmented Control (outer height via `--solaris-control-height-<density>-<size>` tokens, `sm` → `xs`, `md` → `sm`, `lg` → `md` typography). `density` is now `input<T | undefined>` with `effectiveDensity` falling back to `ThemeService.density` (previously defaulted to `'compact'`, shadowing the theme); the host exposes `data-size` + `data-density` (effective). Also adds a `pressed` toggle input (`data-pressed` + `aria-pressed`, Radix Toggle parity; unset renders no `aria-pressed`), `ariaLabel`/`ariaLabelKey` inputs, a dev-mode warning for text-less buttons without an accessible label (use `[solaris-icon-button]` for icon-only), boolean host attributes on the presence pattern (`data-loading`, `data-full-width`), and fixes the loading `aria-label` host binding clobbering consumer labels (now managed imperatively with save/restore), the `wide` shape being silently overridden by the size×density matrix (now sets `min-width`/`padding-inline` directly), the `warning`/`surface` hover/active pair now follows the subtle-hover system (hover stays within the color family with `*-text`, press commits to solid), and the injected `icon` input never updating after first render (now re-applied via `setInput`). The showcase page is rebuilt on the docs-page-layout pattern (single combined appearance+color preview, interactive size-density selectors without appearance, tabs for icon placement, brand icons, states and custom variants, simple installation, props placeholder, full i18n). The preview-code demo surface now wraps with gap between projected items. Follow-ups: badge/count slot parity with `icon-button-badge`, split-button preset, social-button preset, component harness.
