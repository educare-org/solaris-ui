Refresh the dropdown-menu showcase to the docs-page-layout standard and fix outdated icons. The showcase page now uses `docs-page-header` + `docs-section` + `preview-code` + `tabs` with breadcrumbs, prev/next, TOC, installation, and props sections. Showcase icons updated (`gear` → `settings`, `file`/`files` → `file-text`). The `solaris-dropdown-menu-item` and `solaris-dropdown-submenu-trigger` leading/trailing icons now use `[decorative]` instead of a no-op `aria-hidden` host attribute; `iconDecorative` defaults to `true` on the item and was added to the submenu trigger. The in-menu checkbox/radio indicators now follow the standalone `solaris-checkbox`/`solaris-radio` neutral treatment (`neutral-border-default` unchecked, `neutral-text-body` checked with `neutral-text-inverse` checkmark) instead of primary, and the radio ring now uses the border-width token instead of a spacing token. The submenu trigger leading/trailing icon boxes are fixed to match the item leading size (`spacing-8`) with a readable trailing chevron (`spacing-6`), and the trigger gap matches the item gap (`spacing-4`). The trigger `solarisDropdownMenuAppearance` default stays `'outline'` with `surface` as opt-in (docs corrected to match); the showcase appearance tabs now pass explicit values so surface/outline render distinctly.
