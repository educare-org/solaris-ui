Refactor `solaris-pagination` and add an optional `solaris-table` footer slot. Pagination now ships `solaris.navigation.pagination.*` translations for `en-US` and `pt-BR` (including `Linhas por página`, `1–10 de 95`), renders the item-window range (`{{start}}–{{end}} of {{total}}`) instead of `Page x of y`, and accepts an optional `description`/`descriptionKey` leading text (when set, page-size + range + controls group on the right). Navigation buttons lose the boxed chrome (borderless, larger icons, color-only hover, focus ring kept). The page-size selector uses the new borderless `minimal` select/form-field appearance (`value` input is now honored, so the current page size displays; the bordered `surface` panel opens with a fade-in). `solaris-table` gains an optional `ng-template[solaris-table-footer]` rendered inside the frame below the viewport (nothing renders when absent), so pagination can share the table border; the `with-pagination` showcase example now projects pagination into the footer. Also migrates every raw `px` and bare `0` in the table, pagination, and select styles (plus the table selection-column width) to `--solaris-spacing-*` tokens with identical computed values; only the 720px responsive breakpoint keeps `px`. The page-size selector now uses `size="sm"` with an `xs` value in the label color, and exposes new `--solaris-select-*` hooks (trigger gap, chevron size, value min-width with tabular numerals, reserving room for 3 digits in pagination). On narrow viewports (`max-width: 720px`) pagination hides the page-size label and switches the selector to the `outline` appearance.
