Recalibrate `solaris-checkbox` sizes on the new spacing scale (the previous box had shrunk to ~6-12px): explicit 3x3 `size` x `density` matrix for box/checkmark geometry (box 16px on `compact-sm` up to 24px on `comfortable-lg`, checkmark follows size only, label gap now density-owned, label line-height stays per size, checkmark 8px/12px/16px per size). The default `color` is now `neutral` instead of `primary`. `size` is now optional with an `effectiveSize` fallback chain (own input, `solaris-checkbox-group`, `'md'`) and `density` also inherits from the group, exposed through the new `SOLARIS_CHECKBOX_GROUP` token; the group label renders a `*` required marker, and the group list gap follows the recalibrated radio-group scale (6px `compact`, 8px `normal`, 12px `comfortable`) while grid row/column gaps stay tight (2px/4px/6px). Standalone checkboxes render the same `*` marker next to the label and expose `aria-required` on the native input. `solaris-selection-card` gains an explicit `md` size block plus `density` blocks (`gap` + `padding` from density, indicator/dot/media/switch from size), the radio indicator grows to 16-24px, and the internal switch is recalibrated to the P1 `solaris-switch` scale; cards also inherit `size`/`density` from an enclosing `solaris-radio-group` (`SOLARIS_RADIO_GROUP`, with `SOLARIS_RADIO_GROUP_NAME` still providing the native name) and expose `aria-required`. All `var()` fallbacks are removed from checkbox styles. The three showcase pages are rebuilt on the docs-page-layout pattern (checkbox: preview-code per example, tabs for appearance/color/radius, interactive size-density selectors, indeterminate and form demos; checkbox-group: basic/select-all examples, interactive size-density, layout tabs, states, min/max validation, form integration; selection-card: basic/cards-grid examples, interactive size-density, radio/switch mode tabs, media layouts, states, radio-group integration; simple installation, props placeholder, full i18n). Follow-ups: `checkbox-cards grid` points to `selection-card`, group keyboard roving refinement.
