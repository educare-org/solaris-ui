V2-D (chart motion): `line-chart` dataset transitions run as a deterministic `idle → exiting → rescaling → entering → idle` sequence over staged series and axes, so the incoming dataset never leaks into the view early and old/new curves never overlap or blank the canvas: EXIT erases each line with a pen stroke while dots/areas fade in reverse order, RESCALE swaps the staged data with axes faded out/in while the series stay hidden, ENTER redraws each line with the pen dot riding `getPointAtLength` and per-dot reveals tracking the tip instead of flashing early; rapid changes coalesce to the latest pending dataset, tooltips and the selection guide stay disabled until `idle`, and `prefers-reduced-motion` applies the new data synchronously without animation. Transition choreography constants, the dot view and the instance counter live in the new `line-chart/model/line-chart.utils.ts` (realm-robust snapshot capture; `gradientPrefix` without assignment-in-expression). Showcase `chart-shell` list rows animate in two phases inside a single `motion-duration-normal` token window (content `opacity`+`translateX(-8px)` then `scaleY` collapse, `transform`-only; enter mirrored; removal timer aligned to 300ms). Timeline ↔ list display switches fade in with `translateY(8px)` plus a short shimmer sweep masking the reflow — pure CSS on the freshly inserted `@if` nodes, zero TS. SSR-safe (platform/matchMedia/animate guards) with full cancel and cleanup on destroy/retrigger, doubled reduced-motion guard (media + `data-reduced-motion`).
