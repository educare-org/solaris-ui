Refactor `solaris-badge` onto the 3×3 `size` × `density` matrix pattern (9 explicit `[data-size][data-density]` blocks, `density` as `input<T | undefined>` with `effectiveDensity` falling back to `ThemeService.density`). Badge keeps its own compact height ladder (18–34px, display element outside `--solaris-control-height-*`), fixed-height rows with `line-height: 1` single-line math, typography `sm → xs`, `md → sm`, `lg → md`, and icon sizes following the text (`14px / 16px / 18px`). Fixes the single-digit `count` rendering as a vertical pill (circular footprint via `aspect-ratio` + `min-width` equal to the row height, growing horizontally for more digits, `tabular-nums`) and the tiny slot icons (`calc(spacing-1 * 3.5)` ≈ 3.5px, now sized per row through the `solaris-badge-icon` directive host, `::ng-deep` removed). Adds `count`/`max` (`103` → `"99+"` with `title="103"`), `showZero`, `dot` (+ `pulse` ring, reduced-motion safe), `iconOnly` square geometry, `placement` (`inline` + four corners with `offset` and raised z-index), `truncate` (ellipsis + automatic overflow `title`, opt-out available), and `ariaLabel`/`ariaLabelKey` (required for `dot`/`iconOnly`, zero counts use native `hidden`). The showcase page is rebuilt on the docs-page-layout pattern (preview-code per example, tabs for appearance/color, interactive size-density selectors, count/dot/icon/placement sections, simple installation, props placeholder, full i18n). Follow-ups: `icon-button-badge` parity with the new count/dot API, badge harness.
