Redesign the `solaris-form-field` styling gate before P4 Lotes B/C, keeping the P0 contract (9 size x density matrix owning the wrapper `min-height`, delegated input/textarea height, `data-control-type`/`data-control-resize`) and the Lote A regression specs green. Affix cells are now true standardised squares (`--solaris-form-field-affix-size` from the matrix, decoupled from the row height so they stay square when the inner control overflows the wrapper, top-aligned for textarea) with a symmetric layout (prefix keeps its divider, suffix has none, `padding-right: 0` mirrors `padding-left: 0`); shared density values move to the `:host` base and the triple appearance block is collapsed. Focus now renders a real ring (primary, danger when invalid) instead of an invisible outline-only change, and textarea wrapper padding is symmetric. Projected-content rules move from `::ng-deep` to the global `form-field` stylesheet. New `loading` input renders a size-mapped spinner in the suffix slot (suppresses other suffix content, sets `aria-busy`), and the new `[solaris-form-suffix-action]` directive switches the suffix cell to a hug-content variant that sizes a nested `[solaris-button]` to fit (use with `[solaris-form-suffix]` when projecting through preset fields). Showcase gains suffix-action and loading sections with full en-US + pt-BR i18n. Also corrects the in-field input vertical rhythm: a projected `solaris-input` now renders with zero vertical padding inside the field so the wrapper owns the full height and the outer box matches the matrix token exactly (previously the input's own density padding forced the wrapper taller than the token, e.g. `compact` + `sm`/`md` rendered 32.39px instead of 28/32px). Residual: with a `comfortable` theme density inside an `sm` + `compact` field the text line alone still exceeds the box and the wrapper grows gracefully. Fields also adopt their own radius scale (`md` maps to the 8px token, `lg` renders as a pill) so `sm` and `md` stay visually distinct; global radius tokens are untouched. Also replaces the 13 file-level `SECURITY_EXCEPTION_FILE` lines in the field component with 3 line-level justifications at the actual `.nativeElement` uses (host DOM queries are required to detect projected native controls; everything else never matched the security rules). Follow-ups: forward `loading`/suffix-action through preset fields (Lote C), same zero-padding treatment for `select` (Lote B), textarea `autoGrow` + `maxRows`.
