Recalibrate `solaris-radio` sizes on the new spacing scale (the previous control had shrunk to ~6-12px): explicit 3x3 `size` x `density` matrix for control/dot geometry (control 16px on `compact-sm` up to 24px on `comfortable-lg`, dot follows size only, label gap now density-owned, ring width fixed at the border token, label line-height fixed at `--solaris-line-height-none` so the `--solaris-radio-label-line-height` token is gone). Add `description` (`descriptionKey`) secondary text under the label referenced via `aria-describedby`, and `labelPosition` (`'start' | 'end'`, default `'end'`) mirroring the label row. Inside a group, unselected options render faded (label in `--solaris-text-muted`, control at `--solaris-radio-unselected-opacity`) so the current choice stands out, and the default `color` is now `neutral` instead of `primary`. `size` is now optional with an `effectiveSize` fallback chain (own input, `solaris-radio-group`, `'md'`) and `density` also inherits from the group, exposed through the new `SOLARIS_RADIO_GROUP` token (the legacy `SOLARIS_RADIO_GROUP_NAME` keeps providing the native name). Both showcase pages are rebuilt on the docs-page-layout pattern (radio: preview-code per example, tabs for appearance/color/label-position with a description demo, interactive size-density selectors; radio-group: basic/validation examples, interactive size-density, layout tabs, states, form integration; simple installation, props placeholder, full i18n). Follow-ups: card-variant input lives in `selection-card`, group keyboard roving refinement.
