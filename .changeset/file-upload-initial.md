Add the file upload family: `solaris-file-upload` (dropzone/button/avatar variants with a borderless shell, drag and drop, accept/size/count validation, per-file list with progress, retry and remove, URL attach via a full field with divider and ghost action, automatic/manual upload modes, XHR upload handler via `SOLARIS_FILE_UPLOAD_HANDLER`), `solaris-file-list` / `solaris-file-list-item` (kind-aware icons tinted by status), and `solaris-image-editor` (dialog-ready canvas editor with translucent crop mask, circular mask, zoom slider, drag and keyboard pan, 90-degree rotation, PNG/JPEG export). Ships `solaris.file-upload.*` and `solaris.image-editor.*` translation keys (`en-US`/`pt-BR`), new `upload` and `minus` built-in icons, a `forms/file-upload` showcase page, and full specs with CDK harnesses.
