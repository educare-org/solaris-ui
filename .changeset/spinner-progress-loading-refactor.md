Refactor the loading feedback trio (`solaris-spinner`, `solaris-progress`, `solaris-loading-text`) with an adapted `size` × `density` matrix, corrected label semantics, and new loading patterns. `solaris-spinner` no longer renders a visible default label — the indicator is indicator-only unless `label`/`labelKey` is explicit (the `solaris.spinner.loading` fallback now feeds only the accessible name); adds `density` (`compact` | `normal` | `comfortable`, default from `SolarisThemeService`, adjusts the indicator-to-text gap while `size` drives the indicator geometry and the label/percent type scale), `overlay` (absolute zone-centered overlay), `lockScroll` (body scroll-lock while `backdrop` is visible), larger indicator sizes (`sm` 12px, `md` 20px, `lg` 32px, `xl` 80px), and the new `solaris-loading-zone` directive (`aria-busy` + `inert` so fields below stay disabled while loading). `solaris-progress` gains `status` (`active` | `success` | `exception`), `striped` / `animatedStripes`, `bufferValue`, and `density`; `solaris-loading-text` gains `density`, `maxLines`, and `dots`. All three showcases were rebuilt on the docs-page layout (`preview-code` per example, `solaris-tabs` variations, interactive size-density, installation, props). Follow-ups: `delay`/`minimum-duration` anti-flicker for spinner, a fullscreen `SolarisLoadingService`, progress `steps` segments, and loading-text rotating messages.
