Refine `solaris-toast` size/density proportions and countdown stability: `iconSize` now defaults from the card `size` (`sm`→`sm`, `md`→`md`, `lg`→`lg`) so a small toast no longer renders the large `md` glyph — an explicit per-toast or provider `iconSize` still overrides; the glyph scale now matches the title scale exactly (`sm 14px`, `md 16px`, `lg 18px`) and the close glyph scales with `size` (`xs/sm/md`) while keeping the 24–28px hit box; `sm` description steps down to `2xs (12px)` for title/description hierarchy (`sm 14/12`, `md 16/14`, `lg 18/16`) and the countdown footer inherits the description size; the countdown toggle no longer renders a focus outline and the footer stacks a hidden sizer with the starting plural text in the same grid cell as the visible message, so the plural→singular (`N segundos` → `1 segundo`) transition no longer shrinks the card — with no hardcoded widths, following any locale; the loading glyph now spins on its own axis (explicit square icon box with explicit center origin, and the `solaris-icon` host is now grid-centered so the inner inline `svg` no longer sits ~2px off baseline — that offset was orbiting 4px per turn); media container uses visible overflow to avoid clipping the glyph.
