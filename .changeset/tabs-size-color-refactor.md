Add `size` (`sm` | `md` | `lg`, default `md`) and `color` (`primary` | `neutral`, default `primary`) to `solaris-tabs`, with the same 3×3 `size` × `density` matrix as Segmented Control (height via `--solaris-control-height-*` tokens, `sm` → `xs`, `md` → `sm`, `lg` → `md` typography). `solaris-editable-tabs` forwards both inputs to its inner tabs and sizes the rename input from the same matrix. Also fixes the inverted `compact`/`normal` density scale, the `wide` shape referencing the nonexistent `--solaris-density-padding-lg` token, the `pills` radius override order, boolean host attributes now following the presence pattern (`data-full-width`, `data-scrollable`, `data-show-indicator`, plus the new `data-fit-content` binding), a ResizeObserver/MutationObserver/requestAnimationFrame indicator (SSR-safe) replacing the `offsetLeft`/`setTimeout` measurement, wrap-around keyboard navigation with RTL mirroring, `aria-disabled` on the tablist when the group is disabled, an `undefined` `aria-label` fallback instead of hardcoded `"Tabs"`, and unified `--solaris-tab-*` tokens (removed divergent `--solaris-tabs-tab-*` duplicates). Follow-ups: `pills` tabs gain extra horizontal padding for a more regular pill shape, the vertical tablist separates tabs from the separator line via the new `--solaris-tabs-separator-gap` token, and the editable-tabs action trigger glyph follows `--solaris-tab-icon-size` (buttons do not inherit `font-size`, so the ellipsis previously ignored tab sizing).
