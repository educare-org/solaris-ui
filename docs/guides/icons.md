# Solaris UI — Icon System

## Usage

```html
<solaris-icon name="check" />
<solaris-icon name="x" decorative />
<solaris-icon name="info" ariaLabel="Information" />
```

## Inputs

| Input                 | Type                          | Default     | Description                                                |
| --------------------- | ----------------------------- | ----------- | ---------------------------------------------------------- |
| `name`                | `string`                      | required    | Icon name from the registry                                |
| `variant`             | `outline \| solid \| duotone` | `outline`   | Render variant, with fallback when no dedicated art exists |
| `size`                | `number \| string`            | `undefined` | Host width/height (number is px)                           |
| `strokeWidth`         | `number`                      | `2`         | Stroke width for line-based variants                       |
| `absoluteStrokeWidth` | `boolean`                     | `false`     | Keeps stroke width constant when scaling                   |
| `decorative`          | `boolean`                     | `true`      | Hides icon from screen readers                             |
| `ariaLabel`           | `string`                      | —           | Accessible label when not decorative                       |
| `inheritColor`        | `boolean`                     | `true`      | Whether the icon inherits `currentColor`                   |

## Accessibility

- **Decorative icons** (`[decorative]="true"`): set `aria-hidden="true"` and `role="presentation"`. Use when the icon is purely visual and the surrounding text already conveys the meaning.
- **Semantic icons** (default): set `role="img"`. Provide `ariaLabel` when the icon conveys meaning not present in text.
- Icons inside buttons should use `[decorative]="true"` if the button already has a text label.

## Registering custom icons

### 1. Define the icon

```typescript
import type { SolarisIconDefinition } from '@educarehq/solaris-ui';

const myIcon: SolarisIconDefinition = {
  name: 'custom-star',
  viewBox: '0 0 24 24',
  elements: [{ type: 'path', d: 'M12 2l3.09 6.26L22 9.27l-5 4.87 1.18 6.88L12 17.77l-6.18 3.25L7 14.14 2 9.27l6.91-1.01L12 2z' }],
};
```

Supported element types: `path`, `circle`, `rect`, `line`, `polyline`, `polygon`.

### 2. Register via provider

```typescript
import { provideSolaris } from '@educarehq/solaris-ui';

export const appConfig = {
  providers: [provideSolaris({ icons: { extraIcons: [myIcon] } })],
};
```

### 3. Use in templates

```html
<solaris-icon name="custom-star" />
```

## Variants

- `outline`: line art with `currentColor`.
- `solid`: `currentColor` fill for icons with dedicated art (ex: `bookmark`, `mail`, `mic`, `share` dots); otherwise rounded-square knockout fallback (`isFallback() === true`). Outer stroke is always kept.
- `duotone`: `currentColor` layer at 20% opacity behind line art, or dedicated art when available (ex: `rss`, `mail`, `mic`, `link` halves).

Global defaults via `SOLARIS_ICONS_CONFIG` (`defaultVariant`, `defaultStrokeWidth`, `defaultSize`).

## Built-in icons

Solaris ships 209 built-in icons generated by `pnpm icons:build` from `tools/icons/src/outline/*.svg` + `tools/icons/src/solid|duotone/*.svg` overrides + `tools/icons/meta/*.json` (categories, keywords PT/EN, class `fillable|redrawable|stroke-only`, `availableVariants`).

87 icons have `solid` art and 92 have `duotone` art (dedicated + fillable derivation). Icons without dedicated art use a rounded-square fallback (rx ≈ 4px em 24px) that preserves outer stroke. Search by name, keywords, or aliases (ex: `save` → `bookmark`).

No-mod icons (`loader`, `dot`, `slash`, `ellipsis`, `ellipsis-vertical`) render outline in every variant, without fallback. Brand icons render own colors in every variant.

Detail icons (eye, file, files, filter, gear, layers, columns, folder, star, sun, moon, mic, share, link, etc.) use interior art instead of background squares: dots, pupils, document bodies, funnel, gear ring, top layer diamond, grid cells, cursor arrow, chain halves with secondary opacity.

Legacy `groups/*.ts` sources were removed; `SOLARIS_BUILT_IN_ICONS` is generated from `solaris-icons-generated.ts`. `SOLARIS_OUTLINE_SVG` is no longer exported; outline markup comes from the registry via `iconElementsToInner`.

To check if an icon exists at runtime:

```typescript
import { SolarisIconRegistryService } from '@educarehq/solaris-ui';

class MyComponent {
  private registry = inject(SolarisIconRegistryService);

  hasIcon = this.registry.hasIcon('custom-star');
}
```

## Icon colors

The icon inherits the current text color via `currentColor`:

```css
.my-icon-container {
  color: var(--solaris-primary-solid);
}
```

To set a specific icon color, wrap it in an element with the desired color.

## Best practices

- Use existing built-in icons whenever possible
- Keep custom icons in a single file grouped by feature
- Use `decorative` for purely visual icons
- Always provide `ariaLabel` for icons that convey information
- Test icons at multiple sizes — use `font-size` on the parent to scale
- Prefer SVG paths over bitmap images for better scaling and theming
